# MoneyCode Eventówki v2.1 — Paper 1.21.1

Projekt źródłowy Gradle / Java 21. GUI `/mceventowki` dla OP. 7 eventówek: Topór Gromu, Hak Cieni, Miecz Krwi, Gruszka, Kilof Przeklęty, Bomba, Klepsydra Czasu.

## Zmiany
- Usunięty napis `MONEYCODE • EVENTÓWKA` z opisów przedmiotów.
- Nazwy pochodzenia eventówek w formacie `Przedmiot z EVENTU HALLOWEENOWEGO` itd.
- Zasady regionów: spawn blokuje, pvp dozwolone, brak regionu dozwolony, w tym świat lifestealpvp.

## Build na GitHub
Wrzuć zawartość folderu do repozytorium (zachowując `.github/workflows/build.yml`). Actions -> Build -> Artifacts.

## Ważne
To kod źródłowy; nie przeprowadzono tutaj kompilacji i testów na serwerze. Przed produkcją przetestuj efekty, cooldowny, WorldGuard i tekstury.
